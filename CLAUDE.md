# Claude Guidelines

Read `AGENTS.md` and follow it. The critical rule: this is a **public
repo** — never commit personal notes, memory-bank content, session logs, or
real infrastructure/deployment details (IPs, hosts, ports, UUIDs, live URLs,
identities). `memory-bank/` is gitignored and must stay untracked; private
notes go in the fat-platform memory bank on tiny-bat.
